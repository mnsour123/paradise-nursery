# Paradise Nursery – Shopping Cart Application

Paradise Nursery is an online houseplant shop built with **React** and **Redux Toolkit**.

## Features
- Landing page with the company name, background image and a **Get Started** button
- About Us section describing the company
- Product listing with 3 categories and 6 houseplants each (thumbnail, name, price)
- **Add to Cart** buttons that disable after use and update the cart icon count
- Shopping cart page with per-plant totals, overall total, quantity +/- buttons,
  delete button, a **Checkout** button ("Coming Soon") and **Continue Shopping**

## Run locally
```bash
npm install
npm run dev
```
